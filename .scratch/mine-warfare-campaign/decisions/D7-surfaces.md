# D7: Surfaces

**Type:** grilling · **Status:** resolved

## Question
Where does the player see this?

## Answer
A per-area "Mine situation" section in the existing Diplomacy & War screen for
areas of active wars (own laid pressure, suspected enemy pressure, own sweeping
cover, recent incidents); contribution values on the design summary and fleet
screen; incident reports raise the existing alerts count. A map overlay waits
for the strategic map (F-1). The debug simulation tab stays as is.

## Why
These screens exist in production today; a new top-level screen would break the
click-depth ledger for little gain.
