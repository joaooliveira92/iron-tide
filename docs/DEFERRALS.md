# Deferred-work ledger

Work that an ADR records as **deferred** must be tracked here, so a decision that
parks a mechanic for a later milestone cannot be silently dropped. `docs-check`
requires that any ADR whose Status flags a deferral appears in this file, and that
every ADR referenced here exists.

Rows are added when the deferral is recorded and removed when the work lands.

| ADR | Deferred item | Gate |
| --- | --- | --- |
| _none yet_ | No decisions are recorded as deferred. | — |

The ledger is currently empty: no recorded ADR defers any work. When one does,
add a row naming the ADR, the deferred item, and the milestone or gate that
unblocks it.
