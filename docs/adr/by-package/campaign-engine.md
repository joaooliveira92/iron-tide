# ADRs governing campaign-engine

Generated by `pnpm adr:index`. Compact reference combining
repository-wide rules and package-specific rules. Does not replace
the canonical by-scope pages; open an ADR for context and exact
boundaries.

## Repository-wide (apply here too)

- [ADR-0347](../ADR-0347-repository-authority-and-rebaselining.md) Artifacts that never existed in reachable history are unverified legacy references; never recreate them from their filenames.
- [ADR-0351](../ADR-0351-canonical-values-units-fixed-point.md) All authoritative values are stored as canonical fixed-precision types using a single rounding vocabulary; units, currency, and locale convert only at the presentation boundary.
- [ADR-0361](../ADR-0361-deprecate-yaml-outside-internationalization.md) YAML is reserved for internationalization catalogues and mandated infrastructure; all other authored content is declarative TypeScript under constrained domain constructors.
- [ADR-0364](../ADR-0364-worktree-and-git-workflow.md) At most five worktrees including the main checkout; each on its own short-lived branch cut from `dev`; manage through `pnpm worktrees` which uses a locked JSON registry under the Git common directory; merge into `dev` locally after gates are green; one session per checkout.
- [ADR-0365](../ADR-0365-verification-gates-and-infrastructure.md) Verification gates enforce golden-repin discipline, reachability, toolchain integrity and agent scoped checks under `pnpm heavy` serialisation; pipeline artifacts are GitHub Issues; unreachable combat modules stay dormant.
- [ADR-0366](../ADR-0366-adr-code-and-replay-practices.md) Every current ADR states its rule and scope and supersedes acyclically; code carries no comments; the determinism baseline is an approval-gated replay corpus; debug screens stay internal.

## campaign-engine-specific

- [ADR-0352](../ADR-0352-currency-display-language-formatting-boundary.md) Currency is displayed as Naval Credits (default), Budget Points, or National Historical (when a validated configuration exists); UI language and formatting locale are independent preferences; all canonical→display conversions happen exclusively at the presentation boundary.
- [ADR-0353](../ADR-0353-strategic-report-explanation-provenance.md) Every displayed number derives its explanation from stored components or the rule that produced it; report trees are additive persisted fields outside the authoritative hash.
- [ADR-0355](../ADR-0355-readiness-command-structure-and-division-state.md) Every numeric gameplay value for readiness, crew and maintenance is a centralized ruleset constant with provenance; per-nation officer rosters and seeded divisions are authored balance choices; command-lifecycle scaffolding is removed from shipping code; ship conditions are derived predicates computed from existing fields.
- [ADR-0359](../ADR-0359-phase-engine-and-event-architecture.md) Phase order is declared once in `TURN_PHASES`; phases access snapshot aggregates through recorded handles with declared permissions; event body types derive from Effect schemas with no mirrored interfaces.
- [ADR-0362](../ADR-0362-foreign-station-presence.md) S-5 presence is measured at month end from authored ruleset values; nations own possessions in presence areas, deploy ships on foreign station duty, and incur penalties for shortfalls, with exemption for blockade, while base limits constrain over-deployment.
