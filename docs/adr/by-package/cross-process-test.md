# ADRs governing cross-process-test

Generated by `pnpm adr:index`. Compact reference combining
repository-wide rules and package-specific rules. Does not replace
the canonical by-scope pages; open an ADR for context and exact
boundaries.

## Repository-wide (apply here too)

- [ADR-0347](../ADR-0347-repository-authority-and-rebaselining.md) Artifacts that never existed in reachable history are unverified legacy references; never recreate them from their filenames.
- [ADR-0351](../ADR-0351-canonical-values-units-fixed-point.md) All authoritative values are stored as canonical fixed-precision types using a single rounding vocabulary; units, currency, and locale convert only at the presentation boundary.
- [ADR-0361](../ADR-0361-deprecate-yaml-outside-internationalization.md) YAML is reserved for internationalization catalogues and mandated infrastructure; all other authored content is declarative TypeScript under constrained domain constructors.
- [ADR-0364](../ADR-0364-worktree-and-git-workflow.md) At most five worktrees including the main checkout; each on its own short-lived branch cut from `dev`; manage through `pnpm worktrees` which uses a locked JSON registry under the Git common directory; merge into `dev` locally after gates are green; one session per checkout. (amended by ADR-0367).
- [ADR-0365](../ADR-0365-verification-gates-and-infrastructure.md) Verification gates enforce golden-repin discipline, reachability, toolchain integrity and agent scoped checks under `pnpm heavy` serialisation; pipeline artifacts are GitHub Issues; unreachable combat modules stay dormant.
- [ADR-0366](../ADR-0366-adr-code-and-replay-practices.md) Every current ADR states its rule and scope and supersedes acyclically; code carries no comments; the determinism baseline is an approval-gated replay corpus; debug screens stay internal.
- [ADR-0367](../ADR-0367-agent-task-lifecycle-and-merge-authority.md) Every substantial agent task starts from a task brief that names its problem, evidence, acceptance criteria, validation, merge authority and blockers; runs in its own registered worktree and branch; moves through the lifecycle states tracked by `pnpm worktrees status`; returns to a human only at a lifecycle state marked as needing attention; merges only under explicit authority after gates and independent review pass; and ends with an execution report that carries rollback instructions.. Amends ADR-0364.

## cross-process-test-specific

- [ADR-0343](../ADR-0343-save-file-integrity-retention-and-hashing.md) Save files decode with strict schema validation and are integrity-sealed by a complete-file manifest; the snapshot has a single unified hash covering all fields including maps; save retention is opt-in with active and previous saves always protected. (amended by ADR-0368).
- [ADR-0348](../ADR-0348-authored-scope-and-horizon.md) The sole start year is 1880; the authored horizon is 1970; any declared scenario ID with no content pack must not be selectable.
- [ADR-0350](../ADR-0350-e1-1940-1970-content-values.md) Every authored technology, ship class, and part value for the 1940-1970 period must trace to a cited source or be labelled BALANCE_TARGET with a documented derivation; content must never promise behaviour the engine lacks.
- [ADR-0355](../ADR-0355-readiness-command-structure-and-division-state.md) Every numeric gameplay value for readiness, crew and maintenance is a centralized ruleset constant with provenance; per-nation officer rosters and seeded divisions are authored balance choices; command-lifecycle scaffolding is removed from shipping code; ship conditions are derived predicates computed from existing fields.
- [ADR-0363](../ADR-0363-battle-offers.md) Battle offers are raised for eligible missions when the ruleset section is authored; the player may decline at a victory-point cost, repeated declines trigger prestige loss through the S-2 seam, the enemy may decline when outmatched, and a support force may join under defined conditions.
