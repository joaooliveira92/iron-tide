## Repository-wide (apply here too)

- [ADR-0347](../ADR-0347-repository-authority-and-rebaselining.md) Artifacts that never existed in reachable history are unverified legacy references; never recreate them from their filenames.
- [ADR-0351](../ADR-0351-canonical-values-units-fixed-point.md) All authoritative values are stored as canonical fixed-precision types using a single rounding vocabulary; units, currency, and locale convert only at the presentation boundary.
- [ADR-0361](../ADR-0361-deprecate-yaml-outside-internationalization.md) YAML is reserved for internationalization catalogues and mandated infrastructure; all other authored content is declarative TypeScript under constrained domain constructors.
- [ADR-0364](../ADR-0364-worktree-and-git-workflow.md) At most five worktrees including the main checkout; each on its own short-lived branch cut from `dev`; manage through `pnpm worktrees` which uses a locked JSON registry under the Git common directory; merge into `dev` locally after gates are green; one session per checkout.
- [ADR-0365](../ADR-0365-verification-gates-and-infrastructure.md) Verification gates enforce golden-repin discipline, reachability, toolchain integrity and agent scoped checks under `pnpm heavy` serialisation; pipeline artifacts are GitHub Issues; unreachable combat modules stay dormant.
- [ADR-0366](../ADR-0366-adr-code-and-replay-practices.md) Every current ADR states its rule and scope and supersedes acyclically; code carries no comments; the determinism baseline is an approval-gated replay corpus; debug screens stay internal.

## persistence-specific

- [ADR-0338](../ADR-0338-options-and-preferences-and-campaign-command-registry.md) Preferences are a versioned domain object with strict validation and.
- [ADR-0342](../ADR-0342-turn-identity-and-campaign-resume-workflow.md) Turn identity is fixed from pre-execution inputs before any interruption is answered; campaign reopen is gated by a main-process-owned allow-list with canonical-path approval.
- [ADR-0343](../ADR-0343-save-file-integrity-retention-and-hashing.md) Save files decode with strict schema validation and are integrity-sealed by a complete-file manifest; the snapshot has a single unified hash covering all fields including maps; save retention is opt-in with active and previous saves always protected.
- [ADR-0354](../ADR-0354-prestige-and-career-system.md) Prestige is a required nation field; every value is either grounded by RTW3 sources or an explicitly labelled balance target; the application seam is pure and dormant by default; a monthly sacking phase ends the career through a typed terminal record.
- [ADR-0360](../ADR-0360-desktop-ipc-and-process-boundary-architecture.md) Desktop bridge channels are declared once in `shared/ipc-contract.ts`; the command surface is split by concern; UI-state writes are field patches merged once in main; navigation, permission and CSP are guarded from a single policy.
- [ADR-0363](../ADR-0363-battle-offers.md) Battle offers are raised for eligible missions when the ruleset section is authored; the player may decline at a victory-point cost, repeated declines trigger prestige loss through the S-2 seam, the enemy may decline when outmatched, and a support force may join under defined conditions.
