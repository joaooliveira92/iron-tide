# Agent tools

Three commands shorten the discovery and validation loop. They are deterministic, bounded, and safe to run from any subdirectory of the repository.

## `pnpm agent:map <symbol-or-path>`

Reports the owning workspace, the root and scoped `AGENTS.md`, the generated by-scope ADR page with its rule lines, public exports, the file's exported symbols, definition sites, bounded call sites, candidate tests, validation commands, current change state, and golden guidance. `--json` emits the same report as a stable object; `--limit` bounds lists (default 8). JSON fields: `formatVersion`, `query`, `kind`, `owner`, `path`, `instructions`, `rules`, `manifest`, `exports`, `fileSymbols`, `definitions`, `references`, `referenceCount`, `tests`, `validation`, `change`, `goldens`.

Exit codes: `0` found, `2` usage, `3` ambiguous (candidates are listed), `4` not found. It never picks one of several definitions.

Use it before reading a package: it replaces a chain of `ls`, `sed`, `rg` and `git log` turns.

## `pnpm verify:affected [--base <ref>] [--dry-run] [--verbose]`

Reads `pnpm change-scope --base <ref>` (default `dev`), maps changed paths to workspaces, adds reverse dependencies, and runs build, typecheck, tests and lint for each affected unit. Shared configuration, unowned paths and goldens widen the plan; docs, scripts and content changes map to their own units. Work is serialised through the `heavy` lock, full logs land in `node_modules/.cache/bluewave-verify/`, and stdout is one line per unit. `--dry-run` prints the plan.

Exit codes: `0` clean, `1` failure, `2` usage or unknown base, `130` cancelled. It does not replace `pnpm check`.

## `pnpm sprint:show <selector>`

Prints one `.ai/SPRINT-PLAN.md` section, capped at 120 lines. `--list` shows the outline. Ambiguous selectors exit `3`, unknown `4`.

## Long gates

Run long commands blocking through `pnpm heavy <command>`; it serialises across worktrees and forwards signals. Do not background a gate and poll it with `sleep`.

Quote shell separators (`printf '%s\n' '---'`); an unquoted `===` is a zsh glob that aborts the whole command. Discover paths with `git ls-files` before guessing one.

See [change scope](change-scope.md) for the report `verify:affected` consumes.
