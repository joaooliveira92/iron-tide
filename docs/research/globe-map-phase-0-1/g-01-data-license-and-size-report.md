# G-01: data licence and package-size report

Retrieved 2026-10-27 (UTC). Status: **passed-with-limitations**. A legally clean, offline, measured path exists for strategic zoom (z <= ~8). Detail beyond that (the tactical zoom the proposal wants, ~z12) depends on a dataset whose redistribution terms **require legal review**. No dataset passes all criteria for z12 today.

Labels: **[P]** primary-source quotation or fetch, **[M]** measured by script in `g01/`, **[E]** estimate, **[U]** unresolved.

### Geometry quality at the chokepoints **[M]**

Probe coordinates are hand-picked, so a result that is identical across all datasets for one probe is evidence of a bad probe, not of the data. Heligoland and Midway Sand (sub-km islands) were lost by every dataset including OSM and are not conclusive.

| Test | NE 110m | NE 50m | NE 10m (+minor islands) | OSM simplified (24 MB variant) | OSM full-resolution |
|---|---|---|---|---|---|
| Suez Canal reference line on land | 95.2% | 98.7% | **99.7% (absent)** | **24.2% (carved)** | **26.5% (carved)** |
| Panama Canal reference line on land | 100% | 100% | **99.3% (absent)** | **97.9% (absent)** | **97.5% (absent)** |
| Strait probes blocked by land (16 straits) | 0 | Oresund | 0 | 0 | 0 of 7 tested |
| Islands lost (of 17) | 12 | 3 | 2 | 2 | 1 of 6 tested |

Findings: (1) Natural Earth never carries canals; (2) OSM carves Suez but **not** Panama (locks and lakes are mapped as land); (3) therefore **a protected-feature overlay is required for every candidate**, independent of the licence decision. The NE `rivers_lake_centerlines` layer is public domain and contains the Suez and Panama canal centrelines (26 vertices each), a legally clean seed for such an overlay.

**Global extrapolation [E, upper bound]:** scaling the naval-region size by the vertex ratio (x21.1) gives roughly **4 MB (z6), 13 MB (z8), 48 MB (z10), 261 MB (z12)** gzipped. The regions are dense coasts, so this likely overestimates; it is not a measurement of a global build. Build times were small (113 ms for the 1.27 M-vertex Channel region); a global z12 build was not run.

### Not measured

Installed size beyond tiles; memory for representative views from pre-baked tiles (the PoC used runtime GeoJSON tiling, see benchmark report); incremental rebuild; the effect of a naval-band clip (coast strip only) on size; a protected-feature overlay build.

## 3. Pipeline (reproducible; the product pipeline is ticket G-03)

```
cd g01 && npm i shapefile geojson-vt vt-pbf          # build-time only
(download with curl from the official URLs above; verify with SHA256SUMS.txt)
node measure.mjs                                      # NE + OSM-simplified probes and tile sizes
node measure-osm-full.mjs                             # OSM full-resolution region tiles and probes
```

Source acquisition is separate from runtime. The game loads only pre-built tiles from the app resources; no runtime fetch is involved.

## 4. Decision

- **Strategic zoom (z <= ~8): GO.** Natural Earth 10m is public domain, offline, 6.2 MB of tiles to z8, and is already the origin of the baked data. It needs the protected-feature overlay (canals, narrow straits) and 1e-5 degree quantisation instead of the current 0.01 degrees.
- **Tactical zoom (~z10-12): requires-legal-review.** Two candidates, neither cleared: OSM (ODbL, regenerated daily so a pinned snapshot is mandatory) and GSHHG (CC0 vs LGPL conflict). Size looks feasible only with a naval-band clip or per-theatre packs (estimate 48 MB at z10, 261 MB at z12 globally).
- **No-go triggers hit?** None. Redistribution is not prohibited for any candidate; it is undecided for two.

Required next steps: legal read of ODbL for tiles bundled with software (G-01a); written maintainer answer on the GSHHG licence (G-01b); pinned-snapshot and attribution design (notice screen, ADR).
